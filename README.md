# Влияние топологии на распространение болезней

Этот проект исследует влияние топологии сети на распространение инфекционных заболеваний с использованием модели SEIR (Susceptible-Exposed-Infected-Recovered). Проект включает генерацию синтетических данных симуляций на различных типах сетей и анализ полученных траекторий.

## Описание проекта

Проект моделирует распространение болезней на графах с различной топологией:
- **Barabási-Albert сети** (предпочтительная асимметричная сеть)
- Полные графы (Complete graphs)
- Сети Watts-Strogatz (малый мир)

Модель SEIR включает внешний импорт инфекции (новые случаи через Poisson процесс) и сетевые переходы между состояниями.

## Использование

### Генерация данных

Откройте `create_data_regular_networks.ipynb` в Jupyter Notebook или JupyterLab и выполните ячейки последовательно.

Ноутбук содержит:
1. Импорт библиотек и определение функций
2. Визуализацию различных типов сетей
3. Функцию симуляции SEIR с внешним импортом
4. Генерацию данных для различных параметров
5. Сохранение результатов в CSV файлы
6. Анализ и визуализацию полученных траекторий

### Параметры модели

- `N`: Размер сети (по умолчанию 10^4 узлов)
- `tau`: Скорость передачи инфекции
- `alpha`: Скорость перехода из Exposed в Infected
- `gamma`: Скорость выздоровления
- `rho`: Доля изначально инфицированных
- `lam`: Параметр Poisson для внешнего импорта инфекции
- `tmax`: Максимальное время симуляции (дни)

### Формат данных

Каждый CSV файл содержит следующие столбцы:
- `S`: Количество восприимчивых (Susceptible)
- `E`: Количество скрытых (Exposed)
- `I`: Количество инфицированных (Infected)
- `R`: Количество выздоровевших (Recovered)
- `Beta`: Рассчитанный параметр распространения
